Export Telemetry Data for Tableau Analysis

Generates a privacy-compliant CSV containing login records, ML risk scores, and security classifications. Passwords, secret hashes, and sensitive credentials are completely omitted.

Download Tableau Dataset (CSV)
Exported CSV Schema (Data Dictionary)
Column Name Type Description / Privacy Rule
log_id Integer Unique audit identifier.
timestamp Datetime Event time in ISO 8601 UTC.
login_hour Integer Hour of day (0-23) for temporal clustering.
anonymized_user String Masked identifier (e.g. te***@gmail.com). Plaintext hidden.
success_flag Boolean 1 = Successful login, 0 = Failed.
failed_attempt_count Integer Consecutive failed count at moment of attempt.
risk_score Float Isolation Forest anomaly score [0.00 - 1.00].
security_status Category SUCCESS, FAILED, SUSPICIOUS, BLOCKED.
Zero-Knowledge Export: Passwords and password hashes are NEVER exported under any circumstance.
Tableau Connection Instructions
  1. Click the Download Tableau Dataset (CSV) button above.
  2. Open Tableau Desktop or Tableau Public on your computer.
  3. In the left panel under Connect -> To a File, select Text file.
  4. Navigate to your Downloads folder and choose tableau_login_data.csv.
  5. In Tableau's Data Source screen:
    • Ensure timestamp is recognized as Date & Time.
    • Ensure risk_score is recognized as a Number (decimal).
    • Ensure security_status is a String / Dimension.
  6. Click Sheet 1 to begin building your DAV dashboards!
6 Recommended Tableau Visualizations for College Project Submission
Chart 1 Successful vs. Failed Logins
Chart Type: Donut Chart / Side-by-Side Bar Chart
Columns: success_flag
Rows / Marks: COUNT(log_id)
Purpose: Illustrates overall authentication success rate vs malicious brute force attempts.
Chart 2 Suspicious Attempts by Date
Chart Type: Line Trend Chart with Area Fill
Columns: DAY(timestamp)
Rows: COUNT(log_id) filtered by security_status = 'SUSPICIOUS'
Purpose: Visualizes spikes in credential theft and attack bursts over time.
Chart 3 Login Attempts by Hour
Chart Type: Heatmap / Bar Chart
Columns: login_hour (0 to 23)
Rows: security_status
Color: COUNT(log_id)
Purpose: Detects anomalies occurring during irregular hours (e.g., 2:00 AM - 5:00 AM).
Chart 4 Blocked Login Count
Chart Type: Bullet Graph / Single Metric KPI Card
Measure: SUM(IF security_status = 'BLOCKED' THEN 1 ELSE 0 END)
Purpose: Displays the total count of malicious actors halted by the 3-attempt firewall rule.
Chart 5 ML Risk Score Distribution
Chart Type: Histogram / Box-and-Whisker Plot
Measure: risk_score binned into 0.1 increments
Purpose: Demonstrates the effectiveness of the scikit-learn Isolation Forest model separation.
Chart 6 Security Status Summary
Chart Type: Treemap / Stacked 100% Bar Chart
Dimension: security_status
Size / Label: Percentage of Total Logins
