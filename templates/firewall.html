Academic Concept: Layer 7 Application Firewall vs. Network Firewall

Important INS Distinction: This system implements an Application-Level (Layer 7) Security Firewall and Rule Engine. Unlike an OS packet-filtering firewall (e.g. Windows Firewall / Linux iptables) or Network Firewall (which operates at Layer 3/4 on IP headers and TCP ports), an Application Firewall inspects semantic HTTP authentication payloads, prevents brute-force credential stuffing, enforces rate-limiting sliding windows, and statefully locks user accounts.

Active Rule Policies
Rule #1: Max Failed Password Threshold Strict Enforcement

If an account registers 3 consecutive failed attempts, the engine halts further authentication, marks the account status as BLOCKED, and locks the target account for 15 minutes.

Rule #2: IP Sliding Window Rate Limiting DDoS / Bot Throttling

Enforces a maximum of 20 requests per 60-second window per client IP address. Rapid bots or script executions are throttled with HTTP 429 status.

Rule #3: Generic Authentication Responses Anti-Enumeration

Prevents username/email harvesting by returning unified error responses ("Invalid email or password") regardless of whether the email exists in the database.

Rule #4: Session Integrity & CSRF Hardening Session Protection

Cookies configured with HttpOnly=True, SameSite=Lax, and regenerated session identifiers to protect against Session Hijacking and XSS attacks.
